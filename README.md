# Coding Test Study

LeetCode와 프로그래머스를 활용한 SQL · Python 코딩 테스트 스터디입니다.

주 2회 오프라인으로 직접 만나 문제를 풀고, 서로의 코드를 리뷰하며 단순 정답을 넘어서 문제 해결 사고와 쿼리/로직 설계 과정을 공유하는 것을 목표로 합니다.

---

## 스터디 목표

- SQL 및 Python 코딩 테스트 실력 향상
- 문제 접근 방식과 사고 흐름을 언어로 설명하는 연습
- 단순 구현이 아닌 설계 중심 문제 해결 능력 강화
- 코드 리뷰를 통한 다양한 풀이 방식 학습

---

## 진행 방식

- **주 2회 오프라인 스터디**
  - 정해진 장소에서 함께 문제 풀이
  - 개인 풀이 후, 코드 공유 및 리뷰
- 모든 풀이는 GitHub에 기록하여 학습 이력 관리

---

## 일정

1. 스터디 전
   - `weekXX/README.md`에 해당 주차 문제 공지
   - **문제는 오프라인 스터디에서 함께 풉니다.** (사전 풀이 없이 참여합니다.)
2. 오프라인 스터디
   - 문제 함께 풀기
   - 개인별 SQL / Python 코드 작성
   - GitHub에 코드 공유
   - 코드 설명 & 리뷰
3. 스터디 후
   - 리뷰 반영하여 코드 정리
   - (선택) PR 생성 및 추가 코멘트

---

## 파일명 규칙

**공통**

- 파일명은 주차-문제번호 형식으로 작성한다.
- 공백 및 특수문자 사용 금지

**SQL**

- 확장자: `.sql`
- 예시: `1-1.sql`, `2-3.sql`

**Python**

- 확장자: `.py`
- 예시: `1-1.py`, `2-2.py`

---

## 브랜치 전략

- 각자 본인 이름의 브랜치에서 작업한다.
- 작업 완료 후 main 브랜치로 병합한다.
- main 브랜치에는 직접 push하지 않는다.

---

## 커밋 메시지 규칙

- 커밋 메시지는 `weekXX-XX 본인이름` 형식으로 작성한다.
  - 예: `week01-01 김지윤`
